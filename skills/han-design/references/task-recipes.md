# Task recipes

Use these recipes to turn a broad request into a focused Han design brief. Do not combine every recommendation in one page.

## Museum, archive, or heritage

- Mode: historical reconstruction or historically inspired.
- Read: `cultural-methodology.md`, the relevant cultural reference, and `cultural-sources.md`.
- Start with: `ink`, `song`, `qinhan`, `porcelain`, or `dunhuang` only after identifying the actual medium and period.
- Prioritize: object metadata, provenance, captions, chronology, readable long-form text, image alternatives, and restrained framing.
- Avoid: invented inscriptions, generic “ancient” language, decorative sacred imagery, fixed aged colors presented as original colors, and unsupported historical claims.
- Deliver: a short note naming the modern interpretation and the sources that informed it.

## Contemporary brand or landing page

- Mode: contemporary Chinese-inspired.
- Start with: one primary theme and one iconic structure family.
- Prioritize: brand message, conversion path, responsive hero, readable body copy, performance, and editable content.
- Use: seal buttons for one primary ceremonial action; standard buttons for repeated actions.
- Avoid: turning every heading into calligraphy, repeating stamps, and forcing dynasty language onto an unrelated product.
- Deliver: a clear hierarchy with cultural elements subordinate to the brand promise.

## Dashboard, SaaS, or application UI

- Mode: contemporary Chinese-inspired and low visual intensity.
- Start with: `song`, `ink`, `porcelain`, or a scoped token layer over the existing design system.
- Prioritize: information density, tables, filters, status clarity, keyboard use, and familiar interaction patterns.
- Use: Han color, typography, dividers, and small editorial accents around the existing components.
- Avoid: scroll cards for every panel, seal buttons for routine actions, decorative vertical text near controls, and replacing established component behavior.
- Deliver: an application that still feels like the original product, with Han acting as a visual language rather than a new component framework.

## Festival, ceremony, or wedding

- Mode: contemporary Chinese-inspired unless a specific historical reconstruction is requested.
- Read: `motif-semantics.md` before using dragons, phoenixes, rank symbols, religious imagery, or ritual objects.
- Start with: `vermilion`, `tang`, or a restrained custom theme.
- Prioritize: event information, date and location, RSVP, audience, local customs, and print/mobile readability.
- Avoid: asserting universal meanings across periods or regions, combining wedding and funerary symbols, and using red and gold without hierarchy.
- Deliver: culturally scoped wording and a practical information path.

## Tea, craft, or material brand

- Mode: contemporary Chinese-inspired or historically inspired.
- Start with the medium and practice, not “Zen.” Identify tea type, producing region, vessel, craft, material, and social setting when known.
- Start with: `tea`, `celadon`, `porcelain`, `landscape`, or a custom material palette.
- Prioritize: maker, process, origin, material, product detail, brewing or care information, and commerce needs.
- Avoid: Japanese garden shorthand presented as Chinese tea culture, anonymous “ancient craft” claims, and a single muted palette for every regional practice.
- Deliver: source-aware storytelling and functional product information.

## Game, fiction, or entertainment

- Mode: contemporary genre interpretation.
- Start with: `wuxia`, `qinhan`, `tang`, `dunhuang`, or a custom theme according to the fictional world.
- Prioritize: genre clarity, navigation, calls to action, performance, and readable lore.
- State when imagery is fantasy or genre convention rather than historical evidence.
- Avoid: mixing unrelated ethnic, religious, and dynastic symbols merely to signal “ancient China.”
- Deliver: a coherent fictional visual system with clear separation between research and invention.

## Selection shortcut

Before building, write a one-line brief in this form:

```text
Mode + audience + product task + period/region/medium if relevant + primary theme + visual intensity + cultural risks.
```

Example:

```text
Contemporary tea-commerce page for urban mobile buyers; Longquan celadon material reference; celadon theme; subtle ornament; do not claim historical reconstruction or generic Zen authenticity.
```
