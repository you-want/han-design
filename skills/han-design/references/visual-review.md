# Visual review loop

Use this review after the first rendered implementation. A substantial page is not complete after the first pass.

## Required views

- Render one desktop view around 1280–1440 px wide.
- Render one mobile view around 375–430 px wide.
- For long pages, inspect the hero, one dense middle section, and the final action area.
- Inspect open menus, focused controls, errors, empty states, and dialogs when they exist.

## First-glance test

Review the page for five seconds and answer:

1. What is this page about?
2. What should the user do next?
3. Which element receives attention first?

Revise when any answer is unclear or when decoration wins over the product task.

## Craft review

| Area | Check | Revision trigger |
|---|---|---|
| Hierarchy | One dominant headline or task, clear section transitions | Three or more elements compete at the same visual weight |
| Rhythm | Intentional alternation of dense and quiet regions | Repeated identical cards create a flat wall |
| Spacing | Related content is grouped; sections have breathing room | Arbitrary gaps, cramped mobile edges, or oversized empty zones |
| Typography | Display type is limited; body text remains comfortable | Wide tracking on paragraphs, too many font personalities, or long centered copy |
| Color | Functional text and controls remain legible | Decorative palette colors carry low-contrast text or state information |
| Ornament | Cultural details reinforce the content | Stamps, patterns, frames, or vertical text repeat without purpose |
| Media | Imagery adds product, material, place, or story information | Generic images dominate or crop important subjects badly |
| Responsive | Mobile preserves hierarchy instead of merely stacking | Horizontal overflow, giant headings, hidden actions, or awkward card order |
| Interaction | Hover, focus, selected, disabled, loading, and error states are coherent | A screenshot-only state is presented as a working control |

## Mandatory revision

For substantial work, make at least one revision after rendering. Choose the weakest two craft areas rather than adding more decoration. Typical high-value revisions include:

- reducing competing accents;
- rewriting the hero to clarify the promise and action;
- varying card scale or removing unnecessary cards;
- shortening line length and increasing body contrast;
- replacing generic media with a more relevant visual region;
- simplifying the mobile composition;
- lowering visual intensity around forms and dense controls.

Identifying a problem is not the revision. Apply the change, render again, and rerun the failed check. Deliver unresolved actionable issues only when the task is genuinely blocked, and state the blocker precisely.
