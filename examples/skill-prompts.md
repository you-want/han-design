# Han Skill 调用示例

这些示例面向使用 Han 的 AI Agent。调用时直接说明目标项目、内容任务、文化范围和技术栈；不要只说“做得中国风一点”。

## 1. 当代品牌落地页

```text
使用 han-design，为一个面向年轻用户的茶品牌制作移动优先落地页。
使用当代茶空间方向，参考青瓷和自然材质，但不要使用枯山水或宣称历史复原。
保留现有 Astro 项目结构，使用一个主 CTA、产品卡片、产地介绍和购买入口。
完成后检查移动端、键盘焦点、颜色对比度和所有链接。
```

期待 Agent 做到：

- 选择 `tea` 或 `celadon` 作为现代视觉起点；
- 把茶产品信息和购买路径放在装饰之前；
- 不把“禅意”当作中国茶文化的唯一解释；
- 使用功能色 token，不直接用浅色装饰色承载正文。

## 2. 博物馆展览页

```text
使用 han-design，为一个北宋书画专题展制作展览介绍页。
这是历史启发型文化页面，不要把宋代概括成“极简”，并在页面中区分展品信息、当代网页排版和来源说明。
使用现有 HTML/CSS 项目，加入展览时间、地点、展品卡片、作品图片 alt 文本和参观须知。
```

期待 Agent 做到：

- 读取文化方法、朝代边界、书法与来源 references；
- 使用 `song` 时说明它是文人器物启发的当代转译；
- 不编造作者、题跋、印章或年代；
- 优先保证长文本阅读和图像替代文本。

## 3. SaaS Dashboard 国风改造

```text
使用 han-design，只改造当前 React Dashboard 的视觉层，不重写任何交互组件。
希望有克制的水墨和宋式材质感，但需要保留表格、筛选器、分页、弹窗、键盘操作和现有信息密度。
请将 Han token scoped 到 .han-theme 容器，给出需要修改的文件并运行现有测试。
```

期待 Agent 做到：

- 选择 `ink` 或 `song` 的低强度表达；
- 使用目标项目已有的 Modal、Select、Tabs 等行为；
- 不把卷轴、印章、竖排文字铺满 Dashboard；
- 不引入新的框架包或 npm 依赖。

## 4. 节庆或婚礼活动页

```text
使用 han-design，为一个春节活动报名页设计桌面和移动端页面。
需要红色但不要满屏红金；请说明龙凤、灯笼或印章的现代使用语境。
页面必须包含活动说明、日期地点、报名表单、成功状态和错误提示。
```

期待 Agent 做到：

- 选择 `vermilion` 作为节庆起点并控制面积；
- 不写“龙凤是皇家专属”之类绝对判断；
- 表单、错误、成功和焦点状态清楚可读；
- 使用真实 label、button type 和可访问状态。

## 5. 武侠或历史题材游戏页

```text
使用 han-design，为一个架空武侠游戏制作宣传首页。
这是现代类型化想象，不是历史复原；使用玄墨、朱红和卷轴叙事，但不要混合无法解释的宗教或朝代符号。
保留现有 Vue 路由和按钮行为，只负责主题、布局、字体和装饰层。
```

期待 Agent 做到：

- 选择 `wuxia` 作为类型视觉，而不是声称它代表某个朝代；
- 把游戏 CTA、角色信息和剧情入口放在装饰之前；
- 对动画提供 reduced-motion 处理；
- 将真实交互留给现有 Vue 组件。

## 发布前调用检查

生成 standalone HTML 后运行：

```bash
node skills/han-design/scripts/check-output.mjs --strict path/to/output.html
```

复杂页面还应阅读 [输出质量评测](../skills/han-design/references/output-evaluation.md)，不要因为使用了更多 `.han-*` 类就认为结果更好。
